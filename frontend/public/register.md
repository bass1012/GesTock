# Commencez gratuitement avec GesStock

Créez votre espace en quelques secondes. Aucune carte bancaire requise pour le plan Starter.
Le plan Starter inclut :

- 500 produits
- 3 utilisateurs
- Rapports basiques

## Créer un compte (Configuration de l'espace)

Veuillez fournir les informations suivantes pour créer votre espace :

- **Prénom**
- **Nom**
- **Nom de l'entreprise** (ex: Mon Entreprise SARL)
- **Identifiant (URL)** (ex: mon-entreprise.gestock.app)
- **Email**
- **Mot de passe** (8 caractères minimum)
