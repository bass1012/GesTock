# Questions pour le déploiement OVH

Pour préparer un plan de déploiement précis, j'ai besoin de quelques précisions sur votre environnement OVH :

1.  **Type d'hébergement** : Est-ce un **VPS** OVH (fortement recommandé pour Docker) ou un hébergement mutualisé (Web Hosting) ?
2.  **Système d'exploitation** : Si c'est un VPS, quel OS est installé (ex: Ubuntu 22.04 LTS) ?
3.  **Nom de domaine** : Avez-vous déjà un nom de domaine ou sous-domaine qui pointe vers l'IP du serveur ?
4.  **Certificat SSL (HTTPS)** : Souhaitez-vous que je configure la génération automatique des certificats SSL (via Let's Encrypt) ?
5.  **Docker** : Êtes-vous d'accord pour utiliser Docker pour toute la stack (Frontend + Backend + Nginx) ?
